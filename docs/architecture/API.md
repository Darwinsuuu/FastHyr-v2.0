# API contract (FastAPI)

Base URL: `https://api.fasthyr.com/v1`. JSON everywhere; errors are `application/problem+json` with a stable `code`. The OpenAPI schema generated by FastAPI is the precise contract; this document is the map. Every endpoint lists its permission (see `SECURITY.md`).

Headers: `Authorization: Bearer <supabase access token>` (except public), `X-Workspace-Id` (TA endpoints), `Idempotency-Key` (marked ⚷).

## Public (no auth)
| Method & path | Purpose |
|---|---|
| `GET /public/pipelines/{workspace_slug}/{pipeline_slug}` | Apply page data: candidate-safe pipeline fields, status banner, company profile |
| `GET /public/branding/{workspace_id}/{logo\|banner}` | Branding image proxy for emails |
| `POST /public/contact` | Contact form (rate-limited) |
| `GET /public/review-requests/{token}` · `POST …` | Human-review request page (ADR-015) |
| `POST /demo/sessions` · `POST /demo/sessions/{id}/resume-upload` · `PATCH /demo/sessions/{id}` · `POST /demo/sessions/{id}/realtime` · `POST /demo/sessions/{id}/complete` · `DELETE /demo/sessions/{id}` | Public demo (rate-limited, bot-protected) |

## Me (any signed-in user)
| `GET /me` | profile, verified status |
| `GET /me/workspaces` | memberships with role and member counts |
| `POST /workspaces` | create workspace (+ trial credits) |
| `POST /invites/accept` | `{code}` or `{token}` |
| `GET /invites/{code}` | invite preview for the join page |

## Candidate (signed-in candidate)
| `POST /candidate/pipelines/{pipeline_id}/resume-upload` | signed upload URL |
| `POST /candidate/applications` ⚷ | submit application (uses 1 credit) |
| `GET /candidate/pipelines/{pipeline_id}/my-application` | "Applied on…" state |
| `GET /candidate/interviews/{token}` | link state (valid / expired / completed / wrong account / resumable) + interview intro |
| `POST /candidate/interviews/{token}/consent` | record consent (and biometric consent) |
| `POST /candidate/interviews/{token}/session` | start/resume attempt → Realtime client secret, time left, chunk upload URLs |
| `POST /candidate/interviews/{token}/chunk-urls` · `POST …/chunks` | recording uploads |
| `POST /candidate/interviews/{token}/heartbeat` | keep-alive, talk time |
| `POST /candidate/interviews/{token}/complete` | end interview |
| `POST /candidate/interviews/{token}/feedback` | 1–5 rating + comment |

## Workspace (TA) — all require membership via `X-Workspace-Id`
### Workspace admin
| `GET/PUT /workspace/company-profile` · `POST …/branding-upload` | Admin |
| `GET/POST /departments` · `PATCH/DELETE /departments/{id}` | read: member · write: Admin |
| `GET /members` · `PATCH /members/{id}` · `DELETE /members/{id}` | Admin |
| `GET/POST /invites` · `POST /invites/{id}/resend` · `DELETE /invites/{id}` | Admin |

### Dashboard & analytics
| `GET /getting-started` | checklist state |
| `GET /analytics/overview?range=week\|30d` | KPIs, needs attention, funnel, top candidates, live pipelines, weekly, sources, drop-offs, credits |
| `GET /analytics/pipelines-flow?range=` | Pipelines page flow summary |

### Pipelines
| `GET /pipelines?tab=&q=&page=` | list (scoped) |
| `POST /pipelines` · `GET/PATCH /pipelines/{id}` | draft create/edit (PATCH rejected when locked: `pipeline_locked`) |
| `POST /pipelines/{id}/publish` | `{confirm: "I understand"}` → live or scheduled |
| `POST /pipelines/{id}/start-now` · `/pause` · `/resume` · `/close` `{notify}` · `/cancel` · `/archive` · `/duplicate` | lifecycle |
| `POST /pipelines/{id}/top-up` ⚷ `{credits}` | reserve more from free credits |
| `GET /pipelines/{id}/share-links` | tagged URLs per source |
| `GET /pipelines/{id}/dashboard` | KPIs, funnel, daily, histogram, sources, drop-offs |
| `POST /pipelines/{id}/reinvite` `{scope: "all_unfinished"}` | re-invite |

### Applications & candidates
| `GET /pipelines/{id}/applications?stage=&q=&page=` | Candidates tab |
| `GET /applications/{id}` | full profile payload (application, candidate, résumé assessment, assessment, flags, history refs) |
| `GET /applications/{id}/transcript?q=` | transcript segments (search) |
| `GET /applications/{id}/recording-url` · `GET /applications/{id}/resume-url` | signed URLs |
| `POST /applications/{id}/reject` `{reason, send_email}` · `POST /applications/{id}/advance` `{note, send_email}` | Recruiter/Admin |
| `POST /applications/{id}/invite-manually` | for unreadable résumés or overrides |
| `PATCH /integrity-flags/{id}` `{status, note}` | resolve flag |
| `GET /review-requests?status=open` · `POST /review-requests/{id}/resolve` `{outcome: uphold\|override, note}` | human review |
| `GET /candidates?filter=&q=&page=` · `GET /candidates/{id}` · `GET /candidates/dashboard` | pool (read-only) |
| `POST /candidates/{id}/delete` | Admin — data deletion (FR-COMP-05) |

### Ava
| `POST /ava/threads` `{scope, pipeline_id?}` · `GET /ava/threads/{id}` · `POST /ava/threads/{id}/messages` (streams SSE) | scoped to caller |

### Email templates
| `GET /email-templates` · `GET/PUT /email-templates/{key}` · `POST /email-templates/{key}/reset` · `GET /email-templates/{key}/versions` · `POST /email-templates/{key}/versions/{vid}/restore` · `POST /email-templates/{key}/test` | Admin, Recruiter |

### Billing (Admin unless noted)
| `GET /billing/summary` | plan, credits, batches, payment method, billing details |
| `POST /billing/subscribe` `{plan}` · `POST /billing/change-plan` `{plan}` | Checkout / subscription update |
| `POST /billing/portal-session` | Stripe Customer Portal URL |
| `POST /billing/credit-packs/purchase` ⚷ `{pack}` | PaymentIntent (client secret for 3-D Secure) |
| `GET /billing/invoices?page=` · `GET /billing/invoices/{id}` | invoices |
| `PUT /billing/details` | billing details |
| `GET /billing/usage` · `GET /billing/ledger?page=` | Credit usage page (Admin, Recruiter read) |

### Jobs
| `POST /reports` `{kind, params}` · `GET /jobs/{id}` · `DELETE /jobs/{id}` · `GET /jobs/{id}/download-url` | PDF generation with progress |

## Webhooks
| `POST /webhooks/stripe` | signature-verified; stored in `stripe_events` then processed by the worker |
| `POST /webhooks/resend` | delivery status updates |
